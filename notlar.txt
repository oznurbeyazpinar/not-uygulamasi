ls - Dosya ve klasörleri listeler.
cd - Çalışma dizinini değiştirir.
mkdir - Yeni klasör oluşturur.
cat - Dosya içeriğini terminalde gösterir.
rm - Dosya veya klasör siler.

Hafta 2 Git komutları:
git init - Yeni bir Git deposu başlatır.
git status - Çalışma alanı ve staging durumunu gösterir.
git add - Değişiklikleri staging alanına alır.
git commit - Staged değişiklikleri kaydeder.
git branch - Branch listesini gösterir.

# Hafta 2 branch notu: git branch ve git merge komutları tekrar edildi.
